# Archived site material

This directory contains the legacy source files and assets that are no longer
part of the active Stan Brouwer site.

The active site is the collection homepage at `/` and the invite-driven
ticketing flow under `/invites/` and `/tickets/`. The deployment workflow
builds this directory separately and publishes it under `/old`. This keeps the
old blog, personal pages, event implementation, design experiments, fonts, and
supporting assets available without allowing them to participate in active
site routes, layouts, data, or assets.

The directory structure mirrors the original repository paths where practical.
Archived files should not be referenced by active layouts, scripts, styles, or
the live invite data source.
